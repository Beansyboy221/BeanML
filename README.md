# BeanML

**A framework for creating machine learning models.**

BeanML provides a structured base for defining, registering, and loading machine learning models built on PyTorch Lightning. It handles model auto-discovery, checkpoint serialization, optimizer/scheduler configuration, and hyperparameter management.

## Installation

```sh
pip install beanml
```

Read the [Usage Guide](https://github.com/Beansyboy221/BeanML/tree/main/docs/usage.md) to understand all of the features of BeanML and how to use them.
